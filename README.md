# quicknotes-app

QuickNotes is a simple note-taking web application that allows users to create, organise, search and delete notes. Users can assign notes to Personal, Work or Study categories, and notes are saved in the browser using localStorage so that they remain available when the page is reopened.

## Features
- notes
- Categorise notes as Personal, Work or Study
- Display the date and time a note was created
- Delete individual notes
- Search notes
- Case-insensitive note searching
- Validate empty notes
- Limit notes to 200 characters
- Display the number of notes
- Save notes using localStorage
- Load notes when the application opens
- Responsive design for smaller screens
- Different styling for each note category

### How to Run the Project Locally
- Download or clone the project.
- Open the quicknotes-app folder in VS Code.
- Open index.html in a web browser.
- You can also use the Live Server extension in VS Code to run the project locally.
